Core Features

Barcode Table System
Each table in the cafe is assigned a unique ID. A barcode or QR code is generated for each table. When scanned using a mobile device, it opens a digital menu linked to that specific table.

Customer Ordering Interface
A user-friendly mobile web application allows customers to view the menu, select items, and place orders. The order is associated with the table number from the scanned code.

Admin and Staff Panel
A web-based dashboard allows staff to view and manage orders by table, track order status (such as pending, preparing, served, paid), manage menu items, and monitor table occupancy.

Billing and Payment
The system automatically calculates the total bill for each table. It can generate receipts and provide options for both online and offline payment methods.

Inventory Management (Optional)
Track inventory levels of menu items. The system can send alerts when the stock of a particular item is low.
